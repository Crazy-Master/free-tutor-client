# Мобильная шапка и карточка ученика

Изменены переносы и ограничения ширины шапки, сетка разделов карточки,
длинные подписи и размеры элементов управления. Окно подтверждения ограничено
размерами экрана. Бизнес-логика и рабочая база не изменялись.

Проверки перед публикацией: 39 автотестов, TypeScript, production build;
ESLint без ошибок, три существующих предупреждения react-refresh.

Пользователь проверил предпросмотр и сообщил, что всё выглядит хорошо.
Это пользовательская визуальная проверка, не автоматизированная проверка
всех разрешений: инструмент браузерного управления агента был заблокирован.

Повторяемый локальный стенд: `tests/browser/layout.html` после запуска Vite.
Ширины iframe: 320, 375, 390, 768, 1280 CSS px. Данные вымышленные,
сетевые запросы запрещены самим стендом; страницы не входят в production build.
Проверять общую информацию, темы, доступ к решениям, длинные строки и окно
подтверждения смены дисциплины (отмена). Индикатор измеряет ширину документа,
но не заменяет визуальную проверку и проверку удобства взаимодействия.

Граница этапа: только общая шапка и карточка ученика; остальные страницы
не считаются полностью адаптированными. Следующий функциональный этап:
сначала проверить существующую модель и API домашних заданий ученика,
затем реализовать получение назначенного задания и серверную проверку ответа.
