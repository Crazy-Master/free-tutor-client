# Управление разрешениями на решения

В карточку ученика добавлена вкладка «Доступ к решениям». Первая версия использует ввод внутреннего ID задачи банка (не внешнего ID) и отдельную кнопку проверки. Отображаются внешний ID для сверки, эффективный доступ, собственное разрешение преподавателя и наличие других оснований без раскрытия личности другого преподавателя.

Кнопки «Открыть решение» / «Отозвать моё разрешение» используют PUT/DELETE существующего API. После изменения состояние перечитывается с сервера. Если изменение прошло, а повторное чтение не удалось, интерфейс сообщает об этом отдельно. При ошибке устаревшие кнопки скрываются; можно повторить проверку. На время запроса элементы блокируются, повторные отправки защищены также ref-флагом. При изменении ID старый статус очищается; при смене карточки панель перемонтируется.

Если существует другое основание, перед отзывом показано, что доступ сохранится. Приведено предупреждение, что уже просмотренное решение отозвать невозможно. Разметка формы перестраивается из строки в колонку на узком экране.

Сервер дополнен GET /api/solution-access/{relationshipId}/{taskId}. Он проверяет роль teacher, владельца связи и дисциплину задачи и возвращает TaskId, TaskIdExternal, OwnPermission, OtherTeacherPermission, CorrectAnswer, HasAccess. Идентификаторы других преподавателей и содержимое прогресса не выдаются. Миграция не нужна.

Проверки: 37 клиентских тестов (5 новых тестов панели), TypeScript исходников/тестов, production build; 62 серверных теста с дополнительными проверками GET-статуса и авторизации. UI-тесты используют jsdom и подменённый API, серверные — HTTP и временный PostgreSQL. Полный браузерный сценарий в реальной учётной записи и визуальная проверка мобильной ширины не проводились. ESLint имеет прежние предупреждения react-refresh и .eslintignore.

Эта версия не содержит поиска задач по тексту/темам или списка всех ранее выданных разрешений. Проверка правильного ответа ещё не реализована. Клиентский код необходимо опубликовать на Vercel отдельно: локальная сборка не обновляет сайт.
