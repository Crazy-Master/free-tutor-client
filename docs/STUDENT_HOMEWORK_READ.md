# Просмотр ДЗ учеником

Кабинет `/student` показывает назначенные, начатые и завершённые ДЗ из
существующей модели StudentInfoDto. GET `/api/student-to-teacher/student`
определяет ученика по авторизации; клиент не передаёт studentId.
Подписи дисциплин необязательны: при ошибке справочника остаётся ID.
Имена преподавателей существующий контракт не возвращает, показан их ID.

Открытие задачи загружает GET `/api/tasks/{id}` только по выбору пользователя.
Показаны текст и изображение условия; HTML не исполняется. На этом этапе
ответы и решения не отображаются даже при наличии разрешения. Серверная
проверка разрешений при выдаче TaskDto остаётся действующей.

Просмотр не меняет прогресс, статус ДЗ и число попыток. Изменений сервера,
миграций и записей в рабочую базу нет. Повторяющиеся номера ДЗ различаются
по записи связи, категории и позиции; перед реализацией команд отправки
ответа нужно исправить генерацию и согласовать постоянную идентичность ДЗ.

Граница безопасности: существующий API позволяет авторизованному ученику
читать условия банка задач по ID, не только назначенных ему задач.
Доступ к чужим связям/ДЗ от этого не предоставляется. Новое ограничение
банка только назначенными задачами в этот этап не входит.

Клиент: 46 тестов, проверка типов, сборка и ESLint без ошибок
(три ранее существовавших предупреждения). Новые тесты покрывают ленивую
загрузку, повторяющиеся номера, три статуса, ошибки/повтор, отсутствие ДЗ,
безопасный текст и игнорирование ответа после закрытия карточки.

Сервер: все 62 существующих теста прошли на временных PostgreSQL-базах,
включая OwnershipIntegrationTests, TaskDisclosureTests и SolutionAccessTests.
Тестовые базы удалены штатным завершением тестов; рабочая база не изменялась.

Локальный визуальный стенд: `/tests/browser/student-homework.html` через Vite.
Он содержит только вымышленные данные и не входит в production build.
Визуальная проверка нового кабинета ещё не выполнена.
